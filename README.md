1. **买 credits**。入口在 Settings → Usage（Codex 里是 Usage & Billing），有效期 12 个月。credits 覆盖 Codex、ChatGPT Work 和 ChatGPT for Word / Excel / PowerPoint，但不是所有模型和功能都能用它续命。

| 速度模式 | 消耗套餐内用量 | 消耗购买的 credits |

取消订阅不会自动退款。在 ChatGPT 网页端或 Google Play 购买的，联系 OpenAI 支持申请；App Store 购买的直接找 Apple。退款获批后，对应时段的访问权限一般会终止。

**可以年付吗？**
不行。Pro 只有月付，也不能一次预付几个月。

**用量到顶了，能让客服重置吗？**
不能。客服只能核查用量有没有算错、重置后访问有没有恢复，不能手动清零限额。

**保住了老版 Pro 200 的 20x 额度，是不是等于 Pro 500？**
不是。订阅还是 Pro 200，没有 Ultrafast，也没有 Pro 500 的独占功能，只是用量暂时按旧标准计。

**第三方充值会不会把账号搞封？**
OpenAI 明令禁止的是共享凭证、转售访问和自动抓取数据。在自己账号上按流程操作、账号只有自己一个人用，属于正常使用范围；多人共用一个 Pro 账号才是被限制的高发情况。

**撞限额算不算账号被限制？**
不算。模型到限额后只是暂时不可用，等重置即可，订阅本身不受影响。真正会被限制的是违反条款的行为。
